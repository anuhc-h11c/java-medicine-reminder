Java Medicine Reminder

Project Overview

Java-based Medicine Reminder application that allows users to enter medicine names and reminder times. The application uses a graphical interface and scheduled alerts to help users remember their medicines.

Features

- Add medicine names and reminder times.
- Simple graphical user interface using Java Swing.
- Scheduled time checking for reminders.
- Sound notification using an audio file.

Technologies Used

- Java
- Java Swing
- Java Timer and TimerTask
- Java Sound API

Project Files

- "MedicineReminder.java" — Main Java source code.
- "alert.wav" — Sound file used for notifications.

How to Run

1. Install a compatible Java Development Kit (JDK).

2. Download or clone this repository.

3. Open a terminal in the project folder.

4. Compile the program:
   
   "javac MedicineReminder.java"

5. Run the program:
   
   "java MedicineReminder"

Note: Ensure "alert.wav" is in the same folder as the Java program. Use a Java runtime compatible with the JDK used for compilation.
